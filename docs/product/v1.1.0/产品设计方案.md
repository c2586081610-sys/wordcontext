## 二、双模式背词系统

### 2.1 模式一：列表速刷模式（类似炭炭）

**界面布局：**
```
┌─────────────────────────────────────────────────────┐
│  📖 四六级核心词汇 · Unit 3          [切换模式 ⚡]    │
│  ─────────────────────────────────────────────────── │
│                                                       │
│  abandon     /əˈbændən/        ●●●○○  [提示]  │
│  abstract    /ˈæbstrækt/       ●●○○○  [提示]  │
│  accelerate  /əkˈseləreɪt/     ●○○○○  [提示]  │
│  accompany   /əˈkʌmpəni/       ●●●●○  [提示]  │
│  accumulate  /əˈkjuːmjəleɪt/   ●●○○○  [提示]  │
│  ...（10-20 个单词一屏）                              │
│                                                       │
│  ─────────────────────────────────────────────────── │
│  Unit 3: 20词 | 已学 5 | 待复习 3 | 新词 12          │
│  [上一组] [下一组]                                     │
└─────────────────────────────────────────────────────┘
```

**交互逻辑：**

1. **鼠标悬停中间（单词区域）**→ 显示释义提示（半透明浮现）
2. **鼠标悬停右侧（评价区域）**→ 显示三个评价按钮 [😊 熟悉] [😐 模糊] [😣 忘记]
3. **点击评价**→ 自动记录并跳到下一个单词
4. **快捷键支持**
   - `J` / `↓`：下一个单词
   - `K` / `↑`：上一个单词
   - `1`：熟悉  `2`：模糊  `3`：忘记
   - `Space`：显示/隐藏释义
   - `Enter`：播放发音

**v1.1 更新：**
- 速刷模式集成自然拼读展示（可折叠，按 `P` 键展开）
- 全面适配暗色模式样式

## 三、自然拼读发音系统（核心卖点 🔤）

### 3.1 核心规则体系

| 类别 | 规则 | 示例 |
|------|------|------|
| 辅音 | 单字母辅音，一音对一字母 | b→/b/, d→/d/ |
| 辅音组合 | 两个辅音字母组合发一个音 | sh→/ʃ/, ch→/tʃ/ |
| 短元音 | 闭音节中的元音发短音 | a→/æ/, e→/ɛ/ |
| 长元音 | 开音节中的元音发长音 | a→/eɪ/, e→/iː/ |
| R 控元音 | 元音 + r 改变发音 | ar→/ɑːr/, er→/ɜːr/ |
| 魔法 e | 末尾 e 使前面元音变长音 | cake, bike, home |

### 3.2 产品中的实现方式

单词发音可视化拆解，逐音节点击发音，音标独立可听，颜色编码系统（辅音蓝色、元音红色、组合紫色、静音灰色）。

### 3.3 数据模型

```typescript
interface PhonicsBreakdown {
  word: string;
  syllables: string[];
  phonemes: Phoneme[];
  stressIndex: number;
  silentLetters: number[];
}

interface Phoneme {
  grapheme: string;
  ipa: string;
  type: 'consonant' | 'vowel' | 'blend' | 'digraph' | 'r-controlled';
  color: string;
}
```

### 3.4 技术实现

- 音标库：CMU Pronouncing Dictionary 或 eSpeak
- 音节划分算法：最大首音原则（Maximal Onset Principle）
- 发音音频：预录制 44 个英语音标 + Web Speech API 兜底

**v1.1 更新：**
- 音节划分死循环 Bug 已修复（`syllabify()` 中 `i--` 改为 `i = j - 1`）
- 发音质量升级：集成 Edge TTS API（免费、接近真人），Web Speech API 作为离线 fallback

## 四、FSRS 间隔重复系统

### 4.1 FSRS vs 艾宾浩斯

| 对比 | 艾宾浩斯 | FSRS |
|------|----------|------|
| 间隔 | 固定 1-2-4-7-15-30 天 | 个性化动态调整 |
| 参数 | 所有人相同 | 每个用户独立训练 |
| 效率 | 基准 | 比 SM-2 高 20-40% |

### 4.2 三种评价与 FSRS 映射

| 用户操作 | FSRS 评分 | 效果 |
|----------|-----------|------|
| 😊 熟悉 | 4 (Easy) | stability 大幅增加 |
| 😐 模糊 | 3 (Good) | stability 适度增加 |
| 😣 忘记 | 1 (Again) | stability 重置 |

### 4.3 v1.1 新增：FSRS 参数自动训练

| 项目 | 说明 |
|------|------|
| 训练阈值 | 累计 50 次复习后触发首次训练，之后每 50 次重新训练 |
| 训练方式 | 简化版 5 维参数优化算法 |
| 持久化 | 训练后参数保存到 IndexedDB settings 表 |
| 效果 | 算法参数随使用越来越贴合个人记忆特征 |

**5 维训练维度：**

| 维度 | 优化参数 | 依据 |
|------|---------|------|
| 实际记忆保持率 | `request_retention` | Review 状态下成功回忆比例 |
| 首次评价分布 | `w[0]-w[3]` 初始稳定性 | 用户评分倾向 |
| 评价难度分布 | `w[4]` 难度参数 | Again/Easy 比例 |
| 复习间隔表现 | `w[8]` 稳定性增长因子 | 成功/遗忘的平均间隔比 |
| 复习速度 | `w[17]` 短期记忆参数 | Learning 状态下的平均耗时 |
