# 词境 (WordContext) — 项目愿景

> 自然拼读发音 + FSRS 科学记忆 + 语境视频学习 + 双模式背词

---

## 项目使命

**让每一个英语学习者都能「会读、会记、会用」单词。**

---

## 核心价值主张

### 1. 自然拼读 — 会读才会背

音标和单词发音基于 Phonics 规则拆解，可视化展示音节、音素、重音、静音字母。用户不仅能听到发音，更能「看到」单词怎么拆、怎么读。全市场独家功能，填补了背单词应用在拼读教学上的空白。

### 2. FSRS 科学记忆 — 不浪费每一分钟

采用 FSRS（Free Spaced Repetition Scheduler）算法，比传统艾宾浩斯曲线高效 20-40%。算法根据用户个人表现动态调整复习间隔，实现真正的个性化记忆调度，而非一刀切的固定周期。

### 3. 语境视频学习 — 在真实场景中习得词汇

借鉴 DejaVocab 的语境思维，支持用户上传视频或文件，AI 自动提取词汇并绑定语境。从「背了不会用」到「在真实场景中自然习得」，打通输入到输出的最后一公里。

### 4. 双模式背词 — 效率与深度兼得

列表速刷模式（炭炭式）追求极致效率，沉浸详情模式（扇贝式）追求深度理解。两种模式自由切换、共享学习进度，满足不同学习场景和心情下的需求。

## 设计哲学

### 1. 打开就背

零学习成本，不需要理解「语料库」「卡片」等概念。用户打开页面即可开始学习，所有复杂逻辑隐藏在幕后。界面信息密度恰到好处——既不空旷到浪费注意力，也不拥挤到令人焦虑。

### 2. 科学记忆

FSRS 算法个性化调度，不浪费用户时间在已经掌握的词上。每一次复习都是算法精心计算的最优时刻，让记忆投入产出比最大化。参数自动训练让算法随用户成长，越用越准。

### 3. 会读才会背

自然拼读可视化是词境的灵魂。看到单词怎么拆、怎么读，建立字母与发音的直觉映射，从根源上解决「会背不会读」的问题。这不是锦上添花，而是不可或缺。

### 4. 键盘优先

所有操作都有快捷键，效率为王。鼠标是辅助，键盘才是主力。J/K 导航、1/2/3 评价、Space 释义、Enter 发音——双手不离键盘即可完成全部学习流程。

### 5. 数据归你

本地存储，零服务器依赖，数据可自由导入导出。用户的学习数据是最宝贵的资产，绝不应被锁定在某个平台。JSON / CSV 双格式导出，随时备份，随时迁移。

### 6. 渐进增强

核心功能零依赖可用，高级功能按需加载。CMU 词典 3.9MB 懒加载不影响首屏，FSRS 参数训练在数据积累后自动触发，视频语境学习在用户主动上传时才启用。不强迫、不打扰，只在需要时出现。
